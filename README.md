# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, education, and achievements. The portfolio includes a functional contact form powered by Node.js, Express.js, and MongoDB.

---

## 🚀 Live Demo

(https://github.com/Adithi-Arasa/Portfolio-Website)

---

## ✨ Features

- 🎨 Modern and responsive user interface
- 👩‍💻 About Me section
- 🛠️ Skills showcase
- 📂 Projects section
- 📄 Resume download
- 📬 Contact form with backend integration
- 💾 Stores contact messages in MongoDB Atlas
